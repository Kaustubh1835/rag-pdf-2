# PDF-RAG
InsightPDF is an end-to-end, AI-powered Retrieval-Augmented Generation (RAG) platform that allows users to upload multi-page PDF documents and have intelligent, context-aware conversations or generate structured summaries from them. In real-world applications, professionals and students often deal with massive PDF files like research papers, contracts, or textbooks. Traditional search tools rely on basic keyword matching through Ctrl+F, which fails to answer conceptual questions, while passing full documents directly into a Large Language Model exceeds token limits and causes severe hallucinations. InsightPDF solves this by using vector embeddings and semantic search to retrieve only the most relevant document chunks per query and ground the AI model's answers strictly in the uploaded source text.

From an engineering perspective, the system is architected as a decoupled web application with a Next.js 16 App Router frontend written in TypeScript, paired with a FastAPI Python backend dedicated to AI processing. When a user uploads a PDF, the file is securely stored in Firebase Cloud Storage, and its metadata is persisted in a serverless Neon PostgreSQL database using Drizzle ORM. The Python backend ingests the document, splits the extracted text into overlapping chunks to preserve context boundaries, and generates high-dimensional vector embeddings. When a user sends a prompt, the system performs a cosine similarity search across the vector store to fetch the top-K matching text snippets, injecting them as context into the LLM prompt to generate an accurate, grounded answer with instant markdown rendering and streaming responses.

Beyond core document chat, the platform includes project-based workspaces to organize documents, four intelligent summarization modes ranging from concise bullet points to study-focused exam prep, dynamic PDF export functionality powered by jsPDF, and OAuth authentication with Google and GitHub via Firebase. The entire user interface is crafted with Tailwind CSS and Framer Motion to deliver a responsive, glassmorphic design that adapts seamlessly across mobile, tablet, and desktop viewports. Choosing RAG over model fine-tuning ensured that users can upload new PDFs on the fly with zero training overhead, while leveraging Neon DB and Drizzle ORM provided lightweight, serverless database scaling with zero runtime overhead.
